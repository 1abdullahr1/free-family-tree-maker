Build instructions (Windows):

1. Install Flutter and Android SDK. Follow https://flutter.dev/docs/get-started/install/windows
2. Ensure ANDROID_HOME and PATH configured for sdk/platform-tools and flutter bin
3. In project root, run:
   flutter pub get
   flutter build apk --release

The release APK will be at: build\app\outputs\flutter-apk\app-release.apk

If Flutter is not installed on this machine, copy this project to a machine with Flutter to build the APK.
